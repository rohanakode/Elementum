# Elementum - Front-End Development Internship Assessment

##  Built With 
* **Core Library:** React.js (Functional Components, Hooks State Engine)
* **Styling Engine:** Responsive CSS3 (Flexbox, CSS Grid, Media Query Sandboxing)
* **Asset Formats:** SVGs, Alpha-Transparent PNGs
* **Build Tool:** Vite / Create React App (ES6+ Architecture)

Setup & Execution Guide (How to Copy and Run)

Prerequisites:

- Node.js (v16.x or higher)
- NPM Package Manager

1. Clone the Repository
git clone https://github.com/rohanakode/Elementum.git
cd elementum-agency-platform

2. Install Project Dependencies
npm install

3. Run the Development Server
npm run dev

4. Compile Production Build

npm run build
